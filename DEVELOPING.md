# Developing Station Manager (v2)

v2 is under construction on the `main` branch. The final developer-setup
documentation will be written once v2 reaches a stable shape
(post-milestone-1).

Until then, the durable documentation lives in:

- `CLAUDE.md` — project conventions, idioms, invariants, and the docs
  inventory for Claude Code sessions. Read this first.
- `docs/v1-analysis/` — v1 analysis documents; the spec source for v2.
- `docs/v2-design/` — v2 design decisions as they're made. Start with
  `structure.md`.
- `docs/session-handoff.md` — rolling cross-session state. What's done,
  what's next.

For v1 developer setup (the last released version, still runnable for
day-to-day ham radio operations), check out the v1 branch:

```
git checkout v1
cat DEVELOPING.md
```
